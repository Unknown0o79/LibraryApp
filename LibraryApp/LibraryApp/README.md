# LibraryApp

Учебная информационная система учёта библиотеки.

## Структура проекта

- `main.py` — точка входа приложения.
- `database/` — работа с SQLite и инициализация БД.
- `models/` — модели предметной области.
- `services/` — бизнес-логика книг, читателей и выдач.
- `ui/` — графический интерфейс Tkinter.
- `tests/` — автоматические модульные и интеграционные тесты.
- `library.db` — готовая SQLite-база с демонстрационными данными.
- `pytest.ini` — конфигурация тестов.
- `requirements.txt` — зависимости для тестирования.
- `run.bat` — запуск приложения в Windows.
- `test.bat` — запуск тестов в Windows.

## Запуск

Из корня проекта:

```bat
python main.py
```

или дважды нажмите `run.bat`.

## Тестирование

```bat
python -m pytest -q
```

Проверенная сборка: 31 тест, 31 пройден.

Для покрытия:

```bat
coverage run -m pytest -q
coverage report -m
```
