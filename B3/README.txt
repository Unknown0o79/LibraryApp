ЭТАП 3 — БИБЛИОТЕКА

Структура проекта:
main.py                  — точка запуска приложения
library_app/db.py       — создание БД и тестовые данные
library_app/functions.py — пользовательские функции этапа 3
library_app/tests.py    — автоматическое тестирование
library_app/ui.py       — графическое приложение

Запуск:
1. Откройте папку проекта в Visual Studio.
2. Убедитесь, что установлен Python 3.
3. Запустите main.py.
4. Файл LibraryDB.db создастся автоматически.

В приложении реализованы:
- 2 скалярные функции;
- 2 табличные функции (аналог inline table-valued функций);
- 1 многооператорная табличная функция;
- демонстрация функций в приложении;
- тестирование функций.

Примечание: формальное задание этапа 3 рассчитано на SQL Server/T-SQL. Этот проект — рабочая Python/SQLite-реализация той же логики для запуска в Visual Studio без сторонних библиотек.

Важно: при каждом запуске приложение создаёт чистую учебную БД с тестовыми данными, поэтому старые записи выдач не накапливаются и тесты стабильно дают 7/7.
