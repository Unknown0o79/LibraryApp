ЭТАП 4 — БИБЛИОТЕКА — LETOS + VISUAL STUDIO

1) LETOS
- Откройте LibraryDB.db.
- В SQL Editor можно выполнять library_triggers.sql и test_triggers.sql.
- Результаты триггеров видны в audit_changes.

2) VISUAL STUDIO
- Откройте папку проекта.
- Запустите main.py.
- Откроется UI «Информационная система библиотеки — Этап 4».
- Вкладки: Книги, Читатели, Аудит, Триггеры, Демонстрация.
- Кнопки UI выполняют реальные SQL-операции над той же LibraryDB.db.
